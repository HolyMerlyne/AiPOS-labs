### 4. Разъяснение

- **ipconfig** — команда для просмотра параметров сетевого интерфейса: IP-адреса, маски подсети и шлюза по умолчанию. Шлюз имеет значение `0.0.0.0`, поскольку все рабочие станции находятся в одной локальной сети и для обмена данными между ними маршрутизатор не требуется.
- **ping** — команда проверки доступности другого сетевого устройства с использованием протокола ICMP (Echo Request/Echo Reply). Успешное получение ответов и отсутствие потерь пакетов подтверждают корректность IP-адресации и коммутации между рабочими станциями.

# Часть 2. Конфигурация маршрутизаторов

### 1. Топология

Создана топология из трёх маршрутизаторов (модель Cisco 2621XM).

Соединения:
- R1 и R2 соединены через интерфейсы FastEthernet с помощью кабеля *Copper Cross-Over*.
- R2 и R3 соединены через интерфейсы Serial с помощью кабеля *Serial DCE/DTE*. Синхронизация DCE настроена на R2.

**[МЕСТО ДЛЯ СКРИНШОТА 6 — ТОПОЛОГИЯ С МАРШРУТИЗАТОРАМИ]**

*Рисунок 6. Топология сети с маршрутизаторами.*

### 2. Таблица сетевых адресов

| Устройство | Интерфейс | IP-адрес | Маска подсети | Роль |
| :--- | :--- | :--- | :--- | :--- |
| R1 | FastEthernet 0/0 | 172.16.0.1 | 255.255.255.252 | — |
| R2 | FastEthernet 0/0 | 172.16.0.2 | 255.255.255.252 | — |
| R2 | Serial 0/0 | 172.16.0.5 | 255.255.255.252 | DCE |
| R3 | Serial 0/0 | 172.16.0.6 | 255.255.255.252 | DTE |

### 3. Ход конфигурирования

Для настройки маршрутизаторов использовалась командная строка Cisco IOS.

**Настройка R1:**

```text
enable
configure terminal

hostname R1

interface FastEthernet0/0
ip address 172.16.0.1 255.255.255.252
no shutdown
exit

ip route 172.16.0.4 255.255.255.252 172.16.0.2

end
write
```

**Настройка R2 (DCE):**

```text
enable
configure terminal

hostname R2

interface FastEthernet0/0
ip address 172.16.0.2 255.255.255.252
no shutdown
exit

interface Serial0/0
ip address 172.16.0.5 255.255.255.252
clock rate 64000
no shutdown
exit

end
write
```

**Настройка R3:**

```text
enable
configure terminal

hostname R3

interface Serial0/0
ip address 172.16.0.6 255.255.255.252
no shutdown
exit

ip route 172.16.0.0 255.255.255.252 172.16.0.5

end
write
```

Статические маршруты обеспечивают передачу пакетов между сетями, непосредственно подключёнными к R1 и R3, через промежуточный маршрутизатор R2.

### 5. Разъяснение результатов

- **show ip interface brief** — отображает IP-адреса интерфейсов и их текущее состояние. Состояние `up/up` подтверждает работоспособность соответствующего интерфейса.
- **show ip route** — выводит таблицу маршрутизации. Обозначение `C` соответствует непосредственно подключённым сетям, а `S` — статическим маршрутам.
- **ping** — позволяет проверить доступность удалённого узла. Успешные ответы подтверждают возможность передачи ICMP-пакетов между маршрутизаторами.
- **clock rate 64000** — задаёт тактовую частоту на последовательном интерфейсе, работающем на стороне DCE.
- **ip route** — используется для добавления статического маршрута, указывающего путь к удалённой сети через следующий маршрутизатор.

Таким образом, была выполнена настройка интерфейсов маршрутизаторов, добавлены статические маршруты и проведена проверка сетевой связности.
