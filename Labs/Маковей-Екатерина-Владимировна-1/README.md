# Лабораторная работа №1

Студент: Маковей Екатерина

Описание: В ходе выполнения данной лабораторной работы были реализованы TCP-сервер и TCP-клиент с использованием стандартной библиотеки java.net языка Java. Сервер спроектирован по многопоточной архитектуре, что позволяет ему обслуживать несколько подключений одновременно. Клиентское приложение работает в консольном режиме, обеспечивает ведение журнала событий и поддерживает команды управления соединением.

## Вариант 5
**Логика TCP-сервера:**
Сервер накапливает входящий поток символов и анализирует его группами строго по 64 символа. Для каждой сформированной группы вычисляется частота встречаемости каждого символа, после чего клиенту отправляется ответ в формате `<<символ1-количество1>, <символ2-количество2>...>>`. Если в группе оказывается менее 3 уникальных символов, сервер отправляет сообщение об ошибке и принудительно разрывает соединение с данным клиентом.

**Логика TCP-клиента:**
Клиент автоматически подключается к серверу при запуске и позволяет отправлять введенные строки (по нажатию клавиши Enter, так как стандартная консоль Java не позволяет перехватывать клавишу Home без использования сторонних библиотек). 
Клиент поддерживает команду `disconnect` для корректного завершения сеанса. 
Также клиент ведет файл протокола (файл `protocol.log`, создаваемый автоматически), в который записывает:
- время начала и окончания соединения;
- передаваемые серверу строки и время их отправки;
- принимаемые от сервера ответы (статистику) и время их получения.

## Инструкция по запуску
Для работы программы на компьютере должна быть установлена Java (JDK). Все команды выполняются из корневой папки проекта.

1. Компиляция исходных файлов (в терминале):
   ```bash
   javac Server.java Client.java
2. Запуск сервера (откроется терминал, который будет ожидать подключений на порту 8080):
   ```bash
   java Server
3. Запуск клиента (в отдельном окне терминала):
   ```bash
   java Client

Для проверки работы сервера на устойчивость к ошибкам достаточно отправить ему группу из 64 символов, состоящую менее чем из 3 уникальных знаков (например, только буквы "a" и "b"). Сервер должен вернуть ошибку и разорвать соединение.
