# Лабораторная работа №1

Студент: Люкевич Владимир Дмитриевич, ИИ-28

Описание: TCP-сервер и TCP-клиент, подключение первоначально автоматическое , однако есть возможность подключиться к серверу через комманду сonnect <адрес> <порт>, есть возможность разрыва соединения при помощи команды: disconnect <адрес> <порт> и отправка сообщения может осуществляться через клавишу PgDn. Сервер считывает 64 символа и отправляет обратно на клиент сообщение типа <сивол> - колличество, а также проверяет на то, болше чем 3 различных символа сообщении, в противном случает отправляет сообщение об ошибке и принудительно разрывает соединение.

Запуск:
1. `javac server.java client.java`
2. `java server`
3. `java client`
4. В клиенте: `connect 127.0.0.1 8080`, затем `ваш текст` + PgUp.
