## Описание

В ходе работы было разработано клиент-серверное приложение на языке C++ с использованием библиотеки **Winsock2**. Приложение реализует обмен данными по протоколу **UDP** — без установки соединения.

**Сервер:**
- Создаёт UDP-сокет (`SOCK_DGRAM`) и привязывает его к порту **666**.
- В бесконечном цикле принимает датаграммы через `recvfrom`. Так как UDP не требует установки соединения, сервер не использует `listen` и `accept`.
- Разбирает команду `create <имя файла> <текст>`, создаёт файл в своём каталоге и записывает в него текст.
- Отправляет клиенту ответ с размером созданного файла (`sendto`).
- При ошибке (неизвестная команда, отсутствие текста, невозможность создать файл или нулевой размер) отсылает сообщение об ошибке. В отличие от TCP, сервер не «разрывает соединение» (его нет), но отправляет сообщение о завершении сеанса.

**Клиент:**
- При запуске **автоматически настраивается** на адрес сервера `127.0.0.1:666`.
- Позволяет вводить строки с клавиатуры; отправка происходит **по нажатию клавиши Home**.
- Отправляет данные через `sendto` и принимает ответ через `recvfrom`.
- Ведёт **файл протокола событий** `client_log.txt`, в который записываются:
  - время начала и окончания соединения,
  - отправленные строки и время их передачи.
- Поддерживает команду `disconnect <адрес> <порт>`, после которой работа клиента завершается.

**Результат работы:**
Клиент подключается автоматически. Строка `create <filename> <text>`, отправленная по нажатию **Home**, корректно обрабатывается сервером — текст сохраняется в заданный файл. Сервер отвечает клиенту размером созданного файла. В консоли сервера фиксируется факт приёма датаграммы.

## Запуск

**Требования:**
- ОС Windows
- Visual Studio (или MinGW)
- Свободный порт **666**

**Порядок запуска (Visual Studio):**

1. Создайте два проекта в одном решении: `UDP_Server` и `UDP_Client`.
2. Вставьте коды сервера и клиента.
3. Соберите решение: `Ctrl+Shift+B`.
4. Запустите сервер (`UDP_Server`). В консоли появится:
   ```
   UDP SERVER (variant 8: create <filename> <text>)
   Waiting for datagrams on port 666...
   ```
5. Запустите клиент (`UDP_Client`) — через «Отладка → Запустить новый экземпляр».
6. Введите команду в окне клиента, например:
   ```
   create test.txt HelloWorld
   ```
   Нажмите **Home**.
7. Проверьте результат:
   - Клиент получит ответ: `File 'test.txt' created. Size = 10 bytes.`
   - Файл `test.txt` появится в каталоге сервера (`x64\Debug\`).
8. Для завершения работы клиента введите `disconnect 127.0.0.1 666` и нажмите **Home**.

**Сборка через MinGW:**
```bash
g++ -o udp_server.exe udp_server.cpp -lws2_32
g++ -o udp_client.exe udp_client.cpp -lws2_32
```

## Вывод

В ходе выполнения лабораторной работы было разработано клиент-серверное приложение на языке C++ с использованием библиотеки **Winsock2** для протокола **UDP**. Освоены особенности дейтаграммного обмена: отсутствие установки соединения, использование `sendto`/`recvfrom`, а также необходимость самостоятельной обработки ошибок доставки. Реализованы механизмы создания файла по команде `create`, отправки ответа клиенту и ведения файла протокола событий. Показано, что UDP-сервер может обрабатывать несколько клиентов без создания потоков — достаточно одного цикла `recvfrom`, так как каждая датаграмма содержит адрес отправителя.
