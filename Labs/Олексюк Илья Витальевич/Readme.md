## Описание

В ходе работы было разработано клиент-серверное приложение на языке C++ с использованием библиотеки **Winsock2**. Приложение реализует обмен данными по протоколу **TCP**.

**Сервер:**
- Ожидает подключения клиентов на порту **666**.
- Для каждого клиента создаётся отдельный поток (`CreateThread`), что позволяет обслуживать несколько клиентов параллельно.
- Принимает от клиента команду `create <имя файла> <текст>`, создаёт файл в своём каталоге и записывает в него текст.
- Отправляет клиенту ответ с размером созданного файла.
- При ошибке (неизвестная команда, отсутствие текста, невозможность создать файл или нулевой размер) отсылает сообщение об ошибке и разрывает соединение.

**Клиент:**
- При запуске **автоматически подключается** к серверу по адресу `127.0.0.1:666`.
- Позволяет вводить строки с клавиатуры; отправка происходит **по нажатию клавиши Home** (а не Enter).
- Ведёт **файл протокола событий** `client_log.txt`, в который записываются:
  - время начала и окончания соединения,
  - отправленные строки и время их передачи.
- Поддерживает команду `disconnect <адрес> <порт>`, по которой разрывается соединение и завершается работа клиента.

**Результат работы:**
Клиент подключается автоматически. Строка `create <filename> <text>`, отправленная по нажатию **Home**, корректно обрабатывается сервером — текст сохраняется в заданный файл. В консоли сервера фиксируется подключение и обработка сохранения.

## Запуск

### Требования
- ОС Windows
- Visual Studio (любая современная версия)
- Свободный порт **666**

### Порядок запуска

1. **Создайте два проекта** в одном решении Visual Studio:
   - `TCP_Server` — для серверной части;
   - `TCP_Client` — для клиентской части.

2. **Вставьте код** сервера и клиента в соответствующие файлы `.cpp`.

3. **Соберите решение:** `Ctrl+Shift+B`.

4. **Запустите сервер:**
   - В «Обозревателе решений» назначьте `TCP_Server` запускаемым проектом.
   - Нажмите **F5**. В консоли появится:
     ```
     TCP SERVER (variant 8: create <filename> <text>)
     Waiting for connections on port 666...
     ```

5. **Запустите клиент** (не закрывая окно сервера):
   - Кликните правой кнопкой по проекту `TCP_Client` → **«Отладка» → «Запустить новый экземпляр»**.
   - Клиент автоматически подключится к серверу.

6. **Введите команду** в окне клиента, например:
   ```
   create test.txt HelloWorld
   ```
   и нажмите **Home**.

7. **Проверьте результат:**
   - В окне клиента появится ответ: `File 'test.txt' created. Size = 10 bytes.`
   - В окне сервера — информация об обработке команды.
   - Файл `test.txt` с текстом `HelloWorld` появится в каталоге сервера (`x64\Debug\`).

8. **Завершение работы:** введите
   ```
   disconnect 127.0.0.1 666
   ```
   и нажмите **Home** — клиент разорвёт соединение и завершится.

### Файл протокола

Все события клиента записываются в файл `client_log.txt` в каталоге, где находится `TCP_Client.exe`. Пример содержимого:

```
[2026-10-15 14:00:00] === SESSION START ===
[2026-10-15 14:00:00] CONNECT to 127.0.0.1:666
[2026-10-15 14:00:05] SEND: create test.txt HelloWorld
[2026-10-15 14:00:20] DISCONNECT
[2026-10-15 14:00:20] === SESSION END ===
```

## Вывод

В ходе выполнения лабораторной работы было успешно разработано клиент-серверное приложение на языке C++ с использованием библиотеки **Winsock2**. Освоены основные этапы работы с сокетами: инициализация Winsock, создание сокета, установка соединения (`connect`), приём и передача данных (`send`/`recv`), закрытие сокета и деинициализация библиотеки. Реализованы механизмы многопоточной обработки клиентов на сервере и ведения файла протокола событий на клиенте. Приложение корректно обрабатывает команду `create <имя файла> <текст>`, сохраняет данные в файл и уведомляет клиента о размере созданного файла.
