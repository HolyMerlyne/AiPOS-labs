Вариант 3. UDP, Winsock2, порт 666.

## Задача

UDP-сервер и UDP-клиент без установки соединения (`sendto` / `recvfrom`).

**Сервер (задание 2):** по команде `save <файл>` принимает текст до маркера `#end##`, сохраняет файл и отвечает клиенту. Если файл создать нельзя - отправляет ошибку и сбрасывает сеанс.

**Клиент (задание 6):**
- подключение командой `connect <адрес> <порт>` (без автоподключения);
- отправка строки по **PgUp**;
- лог `protocol.log`: TX/RX и время.

## Запуск

Сборка (MinGW):

```text
g++ -o udp_server.exe udp_server.cpp -lws2_32
g++ -o udp_client.exe udp_client.cpp -lws2_32
```

1. `udp_server.exe`
2. `udp_client.exe` (лучше в `cmd`, иначе PgUp может скроллить окно)
3. `connect 127.0.0.1 666` → **PgUp**
4. `save demo.txt` / текст / `#end##` → **PgUp** после каждой отправки

Исходники: `udp_server.cpp`, `udp_client.cpp`.
