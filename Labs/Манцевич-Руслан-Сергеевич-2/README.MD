# Лабораторная работа №2

Студент: Манцевич Руслан Сергеевич, ИИ-28

Описание: UDP-сервер и UDP-клиент. Сервер по команде `find <строка> <имя файла>` ищет строку в текстовом файле и возвращает количество найденных строк. Если строка не найдена — завершает сеанс. Клиент на Swing отправляет данные по клавише PgUp, подключается командой `connect <адрес> <порт>`, ведёт лог-файл.

Запуск:
1. `javac Server.java Client.java`
2. `java Server`
3. В отдельном окне: `java Client`
4. В клиенте: `connect 127.0.0.1 666`, затем `find hello test.txt` + PgUp.
