## Описание реализации

В ходе работы было разработано клиент-серверное приложение на языке Java с использованием библиотеки **java.net**. Приложение реализует обмен данными по протоколу **TCP**.

### Сервер

- Ожидает подключения клиентов на порту **8080** (`ServerSocket`).
- Для каждого клиента создаётся отдельный поток — класс `ClientHandler` наследует `Thread`, что позволяет обслуживать несколько клиентов параллельно.
- Принимает от клиента команду `load <имя файла>`, читает соответствующий текстовый файл из своего каталога (`BASE_DIR = "."`) и построчно передаёт его содержимое клиенту. По окончании передачи отправляет маркер `__EOF__`.
- Если запрашиваемый файл отсутствует или не является обычным файлом, сервер отправляет сообщение `ERROR: file not found: <имя>` и разрывает соединение.
- На неизвестные команды отвечает сообщением `ERROR: unknown command, expected: load <file>`.
- После обработки команды `load` (успешной или неуспешной) соединение закрывается.

### Клиент

Клиент представляет собой GUI-приложение на базе **Swing** с окном, содержащим:
- строку состояния (текущее состояние соединения),
- область протокола событий (прокручиваемое текстовое поле),
- поле ввода строки,
- подсказку по управлению.

**Подключение к серверу** выполняется командой `connect <адрес> <порт>`. Если параметры не указаны при запуске, по умолчанию используются `localhost:8080`. Команда вводится в поле ввода и активируется нажатием клавиши **End**.

**Отправка строк** происходит по нажатию клавиши **End**: введённая строка передаётся на сервер. Если соединение не установлено, выводится сообщение `Cannot send (not connected)`.

**Ведение файла протокола событий** `protocol.txt` (в каталоге запуска клиента). В файл записываются с метками времени:
- момент установки соединения и его параметры (хост и порт),
- отправленные серверу строки и время их передачи,
- принятые от сервера строки и время их приёма,
- момент и причина закрытия соединения (пользователем или сервером),
- сообщения об ошибках подключения.

Запись в файл протокола синхронизирована (используется блокировка `logLock`), что исключает конфликты при одновременном обращении из потока чтения сокета и потока обработки событий Swing.

## Запуск

### Требования

- ОС Windows (или любая ОС с установленной JDK)
- JDK (Java Development Kit) версии 8 или выше
- Свободный порт **8080**

### Порядок запуска

1. **Разместите файлы** `Server.java` и `Client.java` в рабочем каталоге. В этом же каталоге должен находиться текстовый файл, который будет запрашиваться клиентом (например, `test.txt`).

2. **Скомпилируйте классы:**
   ```bash
   javac Server.java
   javac Client.java

3. **Запустите сервер:**
   - В отдельном окне терминала запустите `java Server`.
   - В консоли появится:
     ```
     Server started: ServerSocket[addr=0.0.0.0,localport=8080]
     ```

4. **Запустите клиент** (не закрывая окно сервера):
   - Запустите в консоли `java Client`.
   - Подключитесь к серверу, введя в окне клиента:
   ```
   connect 127.0.0.1 8080
   ```

5. **Введите команду** в окне клиента, например:
   ```
   load test.txt
   ```
   и нажмите **End**.

7. **Проверьте результат:**
   - Если файл существует — его содержимое выведено в окно клиента и записано в `protocol.txt`.
   - Если файла нет — клиент получит `Got from server: ERROR: file not found: test.txt`, соединение будет разорвано.

### Файл протокола

Все события клиента записываются в файл `protocol.txt` в каталоге запуска клиента. Пример содержимого:

```
[2026-10-24 19:17:40] Command: connect 127.0.0.1 8080
[2026-10-24 19:17:40] Connection established: 127.0.0.1:8080
[2026-10-24 19:17:47] Sent to server: load test.txt
[2026-10-24 19:17:47] Got from server: line 1
[2026-10-24 19:17:47] Got from server: hii
[2026-10-24 19:17:47] Got from server: line 3
[2026-10-24 19:17:47] Got from server: __EOF__
[2026-10-24 19:17:47] Connection closed by server: /127.0.0.1:8080
[2026-10-24 19:17:53] Application window closed
```

## Вывод

В ходе выполнения лабораторной работы было успешно разработано клиент-серверное приложение на языке Java с использованием библиотеки java.net. Освоены основные этапы работы с TCP-сокетами: создание серверного сокета (ServerSocket) и ожидание подключений (accept), установка соединения на клиенте (Socket), организация потокового ввода-вывода через BufferedReader/PrintWriter, корректное закрытие сокета. Реализованы механизмы многопоточной обработки клиентов на сервере (класс-обработчик ClientHandler, наследующий Thread) и ведения файла протокола событий на клиенте с метками времени. Приложение корректно обрабатывает команду load <имя файла>, передаёт содержимое файла клиенту с маркером конца передачи `__EOF__`, а при отсутствии файла — уведомляет клиента об ошибке и разрывает соединение. Клиент поддерживает задание адреса и порта сервера командой connect, отправку строк по нажатию клавиши End и потокобезопасную запись всех событий сеанса в файл `protocol.txt`.
