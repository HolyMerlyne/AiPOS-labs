## Описание реализации

В ходе работы было разработано клиент-серверное приложение на языке Java с использованием библиотеки **java.net**. Приложение реализует обмен данными по протоколу UDP (датаграммные сокеты `DatagramSocket / DatagramPacket`).

### Сервер

- Создаёт датаграммный сокет DatagramSocket и ожидает приёма пакетов на порту 666.
- Принимает от клиента команду `load <имя файла>`, читает соответствующий текстовый файл из своего каталога и построчно отправляет его содержимое клиенту отдельными датаграммами. По окончании передачи отправляет маркер `__EOF__`.
- Если имя файла пустое — отправляет сообщение `ERROR: file name is empty`.
- Если запрашиваемый файл отсутствует или не является обычным файлом — отправляет сообщение `ERROR: file not found: <имя>`.
- При ошибке чтения файла — отправляет `ERROR: cannot read file: <сообщение>`.
- На неизвестные команды отвечает сообщением `ERROR: unknown command, expected: load <file>`.

### Клиент

Клиент представляет собой GUI-приложение на базе **Swing** с окном, содержащим:
- строку состояния (текущее состояние сеанса),
- область протокола событий (прокручиваемое текстовое поле),
- поле ввода строки,
- подсказку по управлению.

**Подключение к серверу** выполняется командой `connect <адрес> <порт>`. Если параметры не указаны при запуске, по умолчанию используются `localhost:666`. Команда вводится в поле ввода и активируется нажатием клавиши **End**. При выполнении команды создаётся `DatagramSocket`, устанавливается таймаут приёма `setSoTimeout(3000)` и фиксируется установка сеанса.

**Отправка строк** происходит по нажатию клавиши **End**: введённая строка передаётся на сервер датаграммой. Если соединение не установлено, выводится сообщение `Cannot send (not connected)`.

**Ведение файла протокола событий** `protocol.txt` (в каталоге запуска клиента). В файл записываются с метками времени:
- момент установки соединения и его параметры (хост и порт),
- отправленные серверу строки и время их передачи,
- принятые от сервера строки и время их приёма,
- момент и причина закрытия соединения (пользователем или сервером),
- сообщения об ошибках подключения.

Запись в файл протокола синхронизирована (используется блокировка `logLock`), что исключает конфликты при одновременном обращении из потока чтения сокета и потока обработки событий Swing.

## Запуск

### Требования

- ОС Windows (или любая ОС с установленной JDK)
- JDK (Java Development Kit) версии 8 или выше
- Свободный порт **8080**

### Порядок запуска

1. **Разместите файлы** `Server.java` и `Client.java` в рабочем каталоге. В этом же каталоге должен находиться текстовый файл, который будет запрашиваться клиентом (например, `test.txt`).

2. **Скомпилируйте классы:**
   ```bash
   javac Server.java
   javac Client.java

3. **Запустите сервер:**
   - В отдельном окне терминала запустите `java Server`.
   - В консоли появится:
     ```
     UDP Server started on port 8080
     ```

4. **Запустите клиент** (не закрывая окно сервера):
   - Запустите в консоли `java Client`.
   - Подключитесь к серверу, введя в окне клиента:
   ```
   connect 127.0.0.1 8080
   ```

5. **Введите команду** в окне клиента, например:
   ```
   load test.txt
   ```
   и нажмите **End**.

7. **Проверьте результат:**
   - Если файл существует — его содержимое выведено в окно клиента и записано в `protocol.txt`.
   - Если файла нет — клиент получит `Got from server: ERROR: file not found: test.txt`, соединение будет разорвано.

### Файл протокола

Все события клиента записываются в файл `protocol.txt` в каталоге запуска клиента. Пример содержимого:

```
[2026-10-25 11:46:21] Command: connect 127.0.0.1 8080
[2026-10-25 11:46:21] Session established: 127.0.0.1:8080
[2026-10-25 11:46:31] Sent to server: load test.txt
[2026-10-25 11:46:31] Got from server: line 1
[2026-10-25 11:46:31] Got from server: hii
[2026-10-25 11:46:31] Got from server: line 3
[2026-10-25 11:46:31] Got from server: __EOF__
[2026-10-25 11:46:42] Session closed by user: localhost:8080
```

## Вывод

В ходе выполнения лабораторной работы было успешно разработано клиент-серверное приложение на языке Java с использованием библиотеки `java.net`, реализующее обмен данными по протоколу UDP. Освоены основные приёмы работы с датаграммными сокетами: создание серверного сокета `DatagramSocket` и приём пакетов методом `receive()`, формирование и отправка датаграмм `DatagramPacket` на стороне клиента и сервера, установка таймаута приёма `setSoTimeout()` для предотвращения бесконечного ожидания. Клиент поддерживает задание адреса и порта сервера командой `connect`, отправку строк по нажатию клавиши `End`, приём ответа сервера с обработкой маркера `__EOF__` и сообщений об ошибках, а также потокобезопасную запись всех событий сеанса с метками времени в файл `protocol.txt`.
