## Вариант 9
Сервер имеет возможность работать сразу с несколькими клиентами.
Клиент считывает строку, введённую пользователем. Если эта строка - команда вида "load <имя_файла>", то сервер считает и вернёт нам данные из прочитанного файла, в противном случае, если подобного файла нет - разорвёт соединение.
Для отправки строки пользователь должен подтвердить ввод клавишей PgDn.
TCP-клиент ведёт файл протокола (файл protocol.txt, создаваемый автоматически), в котором записывает:
- время начала и окончания соединения;
- передаваемую серверу строку и время передачи строки;
- принимаемую от сервера строку и время приема строки.

Запуск:

- Компиляция исходников:
>javac Server.java Client.java
- Запуск сервера (из рабочего каталога):
>java Server
- Запуск одного или нескольких клиентов:
>java Client
